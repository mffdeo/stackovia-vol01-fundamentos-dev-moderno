# Post LinkedIn — fechamento do V01

Fechei meu primeiro projeto de fundamentos: o IntraStack Básico.

É uma demo estática de um portal de onboarding fictício, construída para praticar fundamentos antes dos frameworks: HTML semântico, CSS responsivo, JavaScript no navegador, dados mockados, formulário com validação, README, riscos, runbook e changelog.

O aprendizado principal foi diferenciar "funciona na minha máquina" de uma entrega que outra pessoa consegue baixar, rodar e verificar.

Limitação honesta: é estudo/fundamentos. Sem backend, banco, autenticação, Docker, CI/CD ou produção real.

Próximo passo: transformar esta base em uma aplicação frontend profissional no Volume 2.
