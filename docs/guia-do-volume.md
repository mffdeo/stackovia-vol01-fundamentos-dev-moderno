# Guia do Volume 01

## O que é este volume?

O **Volume 01 — Fundamentos do Dev Moderno** é o primeiro livro da Stackovia Learning Series: uma série de 11 volumes que leva você do zero ao sistema real, com portfólio profissional em cada etapa.

Este volume cobre os fundamentos que qualquer desenvolvedor web moderno precisa dominar antes de tocar em framework, banco de dados ou container:

- Como a internet funciona (HTTP, DNS, URL, status codes).
- Como o terminal funciona (5 comandos essenciais, estrutura de projeto).
- Como o Git funciona (versionar é diferente de salvar).
- Como o GitHub funciona (README, Pull Request, primeiro portfólio).
- Como o HTML, CSS e JavaScript funcionam no navegador.
- Como fazer requisições e tratar erros de forma honesta.
- Como publicar o primeiro site estático com segurança.
- Como fechar um release que pode ser mostrado para alguém.

## Como usar este material

Cada capítulo é autossuficiente, mas foi projetado para ser lido em ordem. O projeto integrador — o **IntraStack Básico** — cresce capítulo a capítulo e está disponível como código de referência em [Projeto Integrador](/projeto-integrador).

**Leia no ritmo que fizer sentido para você.** Há leitores que completam um capítulo em 2 horas; há leitores que levam uma semana porque param para criar cada artefato com cuidado. Ambos os caminhos são válidos.

**Execute os exercícios "Mãos à Obra"** antes de avançar. Sem executar, você leu sobre o assunto — mas ainda não tem evidência de que sabe fazer.

**Crie os artefatos de portfólio** (README, docs, diário técnico, screenshots). Eles são a diferença entre "estudei isso" e "posso mostrar que sei fazer isso".

## O universo Stackovia

A **Stackovia** é uma software house fictícia onde você é estagiário de desenvolvimento web. O **Mestre Py** é o mentor técnico: faz perguntas incômodas na hora certa, revisa código com firmeza e não deixa você confundir "rodou na minha máquina" com "entrega pronta".

## Rótulo de maturidade

Cada capítulo exibe um rótulo:

- **Preview** — revisado e publicado, sem revisão externa formal ainda.
- **Em produção** — sendo escrito ou revisado.
- **Final** — versão imutável, incluída no PDF final do volume.
