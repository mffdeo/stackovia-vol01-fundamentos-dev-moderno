## Sobre este volume

Você vai acompanhar os primeiros dias de um estagiário na Stackovia — uma software house fictícia com problemas de negócio reais. Cada capítulo resolve um problema concreto usando ferramentas reais, com evidências que vão direto para o portfólio no GitHub.

**Sem React, sem FastAPI, sem banco de dados, sem Docker ainda.** Fundamentos reais, executados com rigor.

## Projeto integrador

**IntraStack básico** — um portal interno construído do zero ao longo dos 13 capítulos. Começa como arquivos avulsos e termina como site estático publicado, com estrutura rastreável e portfólio documentado.

## Como usar

Leia os capítulos em ordem. Execute os exercícios "Mãos à Obra". Crie os artefatos de portfólio antes de avançar.
